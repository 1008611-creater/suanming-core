# 紫微斗数盘系

四柱与紫微是**两套并列的盘系**，不是同一张盘的不同算法。它们共用时间层与农历层，
但年界、日界、起盘依据各不相同，因此**不可互相换算**，也不共用 `ruleId` 命名空间。
详见 [ADR-0005](decisions/ADR-0005-ziwei-as-second-chart-system.md)。

## 与四柱的口径差异

| 维度 | 四柱 | 紫微 |
| --- | --- | --- |
| 换年 | 立春 | 农历正月初一 |
| 换日 | 子正（通用派）/ 子初（子初派） | 晚子时（23:00 后）进日 |
| 起盘依据 | 节气与干支 | 农历月、时辰、宫位 |
| 时间基准 | 真太阳时定时辰 | 真太阳时定时辰 |
| 性别 | 只影响大运顺逆 | 影响大限顺逆与小限方向 |
| 规则集 | `bazi-core-0.1.0` / `bazi-zichu-0.1.0` | `ziwei-core-0.2.0`（默认）/ `ziwei-core-0.1.0` |

两者的时间层与农历层是**同一份实现**：时区、历史夏令时、真太阳时、朔日与闰月只有一套，
避免同一时刻在两套盘里被算成两个农历日。

## 索引约定

索引错一位就整盘错位，因此全目录统一约定并集中声明在 `src/charts/ziwei/palace.js` 顶部：

| 名称 | 基准 | 范围 | 说明 |
| --- | --- | --- | --- |
| `palaceIndex` | 寅基 | 0=寅 … 11=丑 | 十二宫自寅起布 |
| `branchIndex` | 子基 | 0=子 … 11=亥 | 干支表天然子基 |
| `timeIndex` | 十三值 | 0=早子 … 11=亥，12=晚子 | 取地支时用 `fixIndex(timeIndex, 12)`，晚子自然归子 |

换算：`branchIndex = (palaceIndex + 2) % 12`。

## 计算顺序

顺序不可交换，每一步都是下一步的输入：

```
农历 → 时辰索引 → 年干支 → 命身宫 → 五行局 → 十二宫天干 → 十二宫名
     → 紫微天府 → 十四主星 → 十四辅星 → 生年四化
     → 三十八杂曜 → 命主身主 → 四组十二神 → 大限小限
```

顺序里有三处依赖必须**显式传参而不是各算一次**，否则必然漂移：

| 依赖 | 谁产出 | 谁消费 | 各算一次的后果 |
| --- | --- | --- | --- |
| 五行局 | `fiveElementsClass()` | 起紫微星、大限起运、长生十二神 | 星盘与限运、十二神对不上 |
| 禄存宫位 | 十四辅星 | 博士十二神 | 博士十二神整组错宫 |
| 左辅右弼文昌文曲宫位 | 十四辅星 | 日系杂曜（三台、八座、恩光、天贵） | 四颗日系星整组错宫 |

**五行局只算一次**。它同时是「起紫微星的除数」与「大限起运虚岁」：两处各算一次必然漂移，
会让星盘与限运对不上。实现里 `fiveElementsClass()` 只返回一个 `value`，往下传。

## 与四柱一致的证据分级

规则集里的每条取值同样带 `ruleId` / `evidence` / `source` / `confidence`。
紫微的取值绝大多数是 `traditional`：置信度表达的是**体系内部一致性与流传广度**，
不是算命准确率。唯一带天文可验证成分的是真太阳时（`convention`）。

`iztro`（MIT）在本规则集里登记为 **reference-implementation**：它用于交叉核对安星结果，
不把传统口诀升级成天文事实，也不改变 `evidence` 类别。

## 星曜分层

全盘 66 颗星分三层，用 `tier` 字段标记，而不是靠 `series` 之类的实现细节区分：

| 层 | `tier` | 颗数 | 内容 | 作用 |
| --- | --- | --- | --- | --- |
| 主星 | `major` | 14 | 紫微星系 6 颗、天府星系 8 颗 | 定格局 |
| 辅星 | `auxiliary` | 14 | 六吉（左辅右弼文昌文曲天魁天钺）、六煞（擎羊陀罗火星铃星地空地劫）、禄存、天马 | 定助力与阻力 |
| 杂曜 | `minor` | 38 | 年系 26（含红鸾天喜）、月系 6、日系 4、时系 2 | 定细节 |

`palaces[]` 每宫同时提供 `majorStars` / `auxiliaryStars` / `minorStars` 三个扁平名称数组，
以及带完整信息的 `stars`。**下游必须按 `tier` 取层**：用 `series` 或「有无某字段」来判层，
会在新增星曜时静默出错——0.5.0 加杂曜时，旧测试正是靠这个错误假设把 38 颗杂曜判成了辅星。

## 三十八杂曜的口径

杂曜按「依什么起」分五组，`ruleId` 也按组拆开，一组算错只污染一条事实：

| 组 | 颗数 | 起法 | 依赖 |
| --- | --- | --- | --- |
| 年系 | 24 | 年支、年干或二者组合 | 年干支 |
| 红鸾天喜 | 2 | 红鸾 = 卯宫逆数年支，天喜 = 红鸾 + 6 | 年支 |
| 月系 | 6 | 生月宫索引（解神、天姚、天刑、阴煞、天月、天巫） | 生月 |
| 日系 | 4 | 三台/八座/恩光/天贵 | **日序 + 辅星落宫** |
| 时系 | 2 | 台辅、封诰 | 时辰 |

三处最容易写错、已在代码注释里显式声明的地方：

1. **日系星用「日序」而不是农历日**：日序 = 晚子时取当日，其余时辰取前一日。
   这一位之差会让四颗日系星整体错宫。
2. **天伤、天使按宫位定位**（交友宫、疾厄宫），随命宫移动，与年支无关。
3. **台辅、封诰取时辰时晚子归子**（与早子同宫），不顺延一位。

日系星依赖左辅右弼文昌文曲的**实际落宫**，因此杂曜必须排在辅星之后计算。
实现里这四颗星的宫位是从已安好的星表里取，而不是重算一遍——重算就会与盘面漂移。

## 命主身主的口径

两个「取哪一支」的口径**不同**，这是最容易混淆的一处：

| | 取哪一支 | 取表内第几项 |
| --- | --- | --- |
| 命主 | **命宫地支** | `[0]` |
| 身主 | **生年地支** | `[1]` |

即命主按命宫地支查表（子贪狼、丑亥巨门、寅戌禄存、卯酉文曲、辰申廉贞、巳未武曲、午破军），
身主按**生年地支**查表（子午火星、丑未天相、寅申天梁、卯酉天同、辰戌文昌、巳亥天机）。

身主常被误写成「按身宫地支取」。基准盘恰好可以证伪：命宫在卯、身宫在亥，生年支为酉。
按身宫取会得「天机」，按生年支取得「天同」——与参照实现一致的是后者。

## 四组十二神的口径

| 组 | 起宫 | 方向 | 顺序 |
| --- | --- | --- | --- |
| 长生十二神 | 随五行局（水二/土五→申，木三→亥，金四→巳，火六→寅） | 阳男阴女顺行 | 长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养 |
| 博士十二神 | 禄存宫 | 同长生 | 博士、力士、青龙、小耗、将军、奏书、飞廉、喜神、病符、大耗、伏兵、官府 |
| 将前十二神 | 年支三合（寅午戌→午，申子辰→子，巳酉丑→酉，亥卯未→卯） | 恒顺行 | 将星、攀鞍、岁驿、息神、华盖、劫煞、灾煞、天煞、指背、咸池、月煞、亡神 |
| 岁前十二神 | 年支宫 | 恒顺行 | 岁建、晦气、丧门、贯索、官符、小耗、大耗、龙德、白虎、天德、吊客、病符 |

未提供 `gender` 时，长生与博士十二神为 `null`（它们的方向依赖性别），
将前与岁前照常生成（它们只随年支）——**宁缺勿造**，静默取默认会让女命得到男命结果。

岁前十二神的「大耗」位，中州派写作「岁破」。本工程取通行派，登记为「大耗」。

## 未纳入范围

以下内容**故意不做**，等有可核对的出处与交叉验证再加，而不是先安上再找依据：

- 斗君、流年流月流日流时四化、流曜。
- 四柱神煞与紫微格局判定。
- 完整解释语料——那属于 L5，必须引用事实图中的 `fact_id`，不能反向计算。

原则：**宁可先少安一颗星，也不安一颗出处存疑的星**。盘上多一颗来源不明的星，
比少一颗更危险，因为它看起来同样确定。

## 交叉验证

安星结果已与 `iztro` v2.6.1 官方打包产物逐宫对照：

| 用例 | 项数 | 差异 |
| --- | --- | --- |
| 基准盘 2005-07-13 08:58 东经 118.18 男 | 全盘 | 0（宫名别名除外） |
| **十二张参照盘**（1949—2030，男女各半，含闰月与跨年） | **144 宫 × 9 项** | **0** |
| 闰月专项（2023 闰二月、2025 闰六月） | 21 | 0 |
| 随机批次（1940—2025） | 48 | 0 |
| 早晚子时密集 | 22 | 0 |
| 大限 | 12 限 | 0 |
| 小限 | 208 | 0 |

**十二张参照盘的逐项内容**：每宫的 `major` / `auxiliary` / `minor` 三层星曜、
`changsheng12` / `boshi12` / `jiangqian12` / `suiqian12` 四组十二神，
外加全盘的五行局、命宫、身宫、命主、身主。这层验证写死在
`tests/ziwei-cross-reference-smoke.js` 里（**不依赖 .ref 目录**，CI 可独立复现），
专门用来抓「一张盘全绿、换个生日就错」的口径偏移。

唯一系统性差异是宫名：通行派称「交友」，古法称「奴仆」，`iztro` 用「仆役」。
这已作为别名登记在规则集 `palaceNames.aliases` 中，由 `palaceNameAliases()` 导出，
而不是让下游各自猜测。名称不影响星曜分布。

## 用法

```js
import { castZiwei, validateZiweiChart, auditFactGraph } from 'suanming-core';

const chart = castZiwei({
  year: 2005, month: 7, day: 13, hour: 8, minute: 58,
  longitude: 118.18, timezone: 'Asia/Shanghai', gender: 'male'
});

chart.palaces;        // 十二宫：宫干、宫支、宫名、三层星曜、四化、四组十二神、大限、小限
chart.palaces[0].majorStars;      // 本宫主星（14 主星层）
chart.palaces[0].auxiliaryStars;  // 本宫辅星（14 辅星层）
chart.palaces[0].minorStars;      // 本宫杂曜（38 杂曜层）
chart.stars;          // 全盘 66 颗星，各带 tier / group / palaceIndex / branch / palaceName
chart.masters;        // 命主与身主（soulMaster / bodyMaster 及取用支）
chart.twelveGods;     // 四组十二神（含起宫与方向）
chart.soul;           // 命宫
chart.body;           // 身宫
chart.fiveElements;   // 五行局（含局数 value）
chart.mutagens;       // 生年四化
chart.decadal;        // 大限顺逆与十二限
chart.xiaoxian;       // 小限起宫与方向
chart.facts;          // 事实图，每条带 rule_id
chart.manifest;       // 版本清单

validateZiweiChart(chart).valid;   // 结构校验
auditFactGraph(chart.facts).ok;    // 溯源审计（按清单解析盘系规则集）
```

未提供 `gender` 时，`decadal` 与 `xiaoxian` 为 `null`，而不是编造一个默认性别——
编造会让「男顺女逆」静默变成男命结果。
