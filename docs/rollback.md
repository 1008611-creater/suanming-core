# 回滚方案

## 触发条件

出现以下任一情况即触发回滚：入口无法加载、引擎脚本 4xx/5xx、黄金盘与本地结果不一致、控制台出现未捕获错误、或发现个人资料/凭据进入公开产物。

## 执行步骤

1. 停止当前发布，不继续覆盖服务器上的其他站点。
2. 取上一个已通过 `npm run verify` 的部署产物或 Git 提交，恢复 `app/` 静态文件。
3. 清理入口 HTML 的缓存（入口使用 `no-cache, must-revalidate`；静态资源按部署平台策略刷新）。
4. 在真实浏览器重新验证首页、排盘页、自检页、空输入和一个合成黄金盘。
5. 在 `docs/acceptance.md` 记录触发原因、恢复时间、验证结果和后续修复任务。

## 数据与隐私

本项目核心为静态确定性计算，不依赖服务端持久化用户命盘。若触发隐私事件，除回滚外还必须隔离公开产物、轮换相关凭据并按 `SECURITY.md` 的私下渠道报告。
