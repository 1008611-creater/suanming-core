# 详批报告模板（可复用）

> 用法：复制本文件为「客户名-命理详批.md」，把【】占位替换成实际内容。
> **不可省略的两章：〇（验证与认账）、十六（可核验前瞻）。** 这两章是本产品和市面算命的分界线，删了就等于自降身价。

---

## 交付前自检清单（缺一项不交付）

1. 真太阳时是否按出生地经度校正？是否跨时辰？跨了必须做双盘比对。
2. 出生地是否确认到市/县级？没给出生地 → 不排盘。
3. 前事验证是否**先出判断、后看客户答案**？顺序颠倒 → 本次不算验证。
4. 每条判断是否附了推导依据（哪个宫、哪个十神、哪组刑冲合害）？
5. 判错的是否逐条写明并给出错因？只报喜不报忧 → 退回重写。
6. 前瞻是否给到**具体月份区间 + 干支 + 可对账的判词**？
7. 是否标注了不确定项与免责（医疗 / 投资 / 法律）？
8. 对外展示版是否删净了真实姓名、精确生日、出生地、可识别事件？

## 篇幅基准

| 产品 | 字数 | 章节数 |
|---|---|---|
| 单人详批 | 15000–25000 | 15–20 |
| 合婚定级 | 8000–15000 | 12–16 |
| 年运详批 | 4000–8000 | 6–8 |
| 单项批 | 2000–4000 | 4–6 |

低于下限，客户会觉得「就这？」；高于上限，客户读不完。
