# 定盘问卷（客户填写）

> 交付质量的上限，取决于这份问卷的完成度。
> **必须完整填写，尤其是「前事核对」部分 —— 那是验前事的唯一依据。**

---

## 一、基本信息（必填）

1. **姓名**（或化名）
2. **性别**
3. **出生日期**（公历，精确到日）
4. **出生时刻**（尽量精确到分钟；不确定请注明）
   - ⚠️ 若不确定时辰，请说明「大概几点」或「天亮前/上午/中午/下午/傍晚/夜里」
5. **出生地**（精确到市/县，**必须填** —— 用于真太阳时校正与命卦）
6. **现居地**

> **为什么出生地必须填：** 真太阳时校正需要经度。同一天同一时刻，成都出生与唐山出生，
> 可能差 1 个时辰，整盘结论会完全不同。

---

## 二、关注重点（可多选）

- [ ] 事业 / 职业方向
- [ ] 婚姻 / 感情
- [ ] 财运 / 投资方向
- [ ] 学业 / 考试
- [ ] 家居风水（八宅 / 玄空）
- [ ] 姓名分析 / 改名
- [ ] 流年运势（请注明年份）
- [ ] 合婚（需另填对方信息，见第四节）
- [ ] 健康（**仅作参考，不替代医疗意见**）

---

## 三、前事核对（**最关键，请务必填写**）

> 命理不能「算准未来却说不清过去」。我们会先给出 3–5 条关于**已发生之事**的判断，
> 请你逐条打分。**验不准，本单不收费。**
>
> 为了让验证有意义，请你先回答下面几个基础问题（我们会在给出判断后再看你的答案，
> 你填写的内容不会被用来「顺着你说」）：

1. **最高学历 / 目前学业状态**
2. **目前的职业方向**
3. **婚姻状态**（未婚 / 恋爱中 / 已婚 / 离异）
4. **兄弟姐妹情况**（几个，同父/同母/同父同母）
5. **父母状况**（是否完整；如有变故请注明大致年份，不必说细节）
6. **近三年最重大的两件事**（不用写细节，给个方向即可，如「换工作」「亲人去世」「搬家」）
7. **感情经历大致情况**（几段，大致起止年份）

> ⚠️ 以上信息仅用于验证准确性，我们**不会**根据你的答案反推结论。
> 验证报告会同时给出「盘面推导依据」，你能看到每条结论是从哪个结构推出来的。

---

## 四、合婚补充（如选填）

对方信息：

1. 姓名（或化名）
2. 性别
3. 出生日期（公历）
4. 出生时刻
5. **出生地**（同样必须填）
6. 关系现状（恋爱中 / 订婚 / 已婚）
7. 你希望重点看什么（是否合适 / 婚期 / 相处模式 / 家庭阻力）

---

## 五、家居风水补充（如选填）

1. 房屋朝向（**以入户门或大窗为准**，可用手机指南针测）
2. 户型图（手绘拍照即可，需标出**入户门位置**和**朝向**）
3. 主要困扰（失眠 / 财运 / 健康 / 家庭关系 / 事业）
4. 房屋类型（楼房 / 平房 / 自建 / 租住）
5. 主要居住人及各自出生年份
