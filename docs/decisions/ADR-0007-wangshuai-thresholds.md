# ADR-0007：旺衰分档阈值随计权口径切换

- 状态：已接受
- 日期：2026-09-17
- 相关：[规则集](../rule-sets.md)、[ADR-0006](ADR-0006-web-single-engine-source.md)

## 背景

页面上的「日主强弱」由**同党占比**决定：

```
ratio = (比劫 + 印) / (比劫 + 印 + 食伤 + 财 + 官杀)
```

原来的分档阈值是一组固定常数（0.62 / 0.52 / 0.44），
来自藏干权重较细的口径。但默认规则集 `bazi-core-0.1.0` 的藏干权重是 `[1, 0, 0]`，
**只取本气**，于是五行分值全为整数，`ratio` 只可能落在 8 个离散值上（步长 0.125）：

```
0, 0.125, 0.25, 0.375, 0.5, 0.625, 0.75, 0.875
```

固定阈值 0.62 落在 0.5 与 0.625 之间，「偏强」这一档**永远取不到**。
实测 4000 份样本：身强 0%、偏强 0%，分档退化成三档。
用户看到的是一个结构性失真的标签，而不是流派分歧。

## 决策

1. 阈值表按**计权口径**（`method`）分别标定：

   | 口径 | 身强 | 偏强 | 中和偏弱 |
   | --- | --- | --- | --- |
   | `bazi.wuxing.element-count`（权重 `[1,0,0]`） | 0.6875 | 0.5625 | 0.4375 |
   | `bazi.wuxing.element-weighted`（权重 `[1,0.5,0.3]`） | 0.62 | 0.52 | 0.44 |

   计权口径的阈值取在离散值之间（如 0.5625 落在 0.5 与 0.625 中间），
   使四个档位都能取到；计重口径取值连续，沿用原阈值。
2. 阈值表放在解释层（`web/analysis.js`），因为这是**分档口径**而非历法事实。
3. 旺衰结果必须回传 `method` / `ruleSet` / `weights` / `thresholds`，
   页面据此说明「这个档位是按哪套口径分出来的」。

## 标定结果

4000 份随机样本，`bazi-core-0.1.0` 口径：

| 档位 | 占比 |
| --- | --- |
| 身强 | 9.9% |
| 偏强 | 20.0% |
| 中和偏弱 | 28.4% |
| 身弱 | 41.8% |

四档都取到，且分布与「同党占比」的自然分布一致。

## 后果

- 换规则集时，分档口径随之切换，不会出现某一档永远为空。
- 解释层从此带有一个可标定的参数表；新增口径必须同时给出阈值与标定依据。
- 这是一次**解释口径修正**，不影响四柱、大运、流年等历法结果。

## 被否决的方案

- **只改默认口径为 `[1,0.5,0.3]`**：等于用改口径来回避分档问题，
  且会让「藏干只取本气」这一常见流派无法使用。
- **把阈值做成连续函数（如正态分位）**：听起来更「科学」，但命理分档本是约定，
  用统计分布反推约定值属于事后合理化，反而更难解释。
