# ADR-0008：真太阳时必须包含均时差

- 状态：已接受
- 日期：2026-09-17
- 相关：[天文模型](../astro-model.md)、[校验记录](../validation.md)

## 背景

真太阳时 = 钟表时间 + 经度时差 + 均时差。

经度时差是纯几何量：`(经度 − 120) × 4` 分钟。均时差来自地球轨道偏心率与黄赤交角，
一年内在 **−14 分到 +16 分**之间变化。

原实现只做了经度修正，均时差按 0 处理。后果是：

- 出生时刻靠近时辰交界时，时柱会错一柱；
- 误差随季节系统性变化，不是随机噪声——2 月中旬约 −14 分，11 月初约 +16 分。

例：`2005-07-13 09:05 @120°`，均时差约 −5.7 分钟，
真太阳时实际仍在辰时；忽略它就会算成巳时。

## 决策

1. 在时间层实现 `equationOfTimeMinutes`（Meeus 第 28 章），
   由 `src/time/shichen.js` 在未显式传入时自动计算。
2. `shichenOfCivil()` 的返回值包含 `equationOfTimeMinutes`，
   四柱与紫微**共用同一份时间层**，因此两盘不会各用一套时间口径。
3. 显式传入 `equationOfTimeMinutes: 0` 时按「钟表时间」处理，
   保留给需要民用时口径的用户，并在页面上标注「未启用」。
4. 网页的「钟表时间」选项实现为**经度 120° + 均时差 0**，
   而不是把两个修正分别关掉，避免出现「半修正」的第三态。

## 验证

- 参考值：`equationOfTimeMinutes(2448908.5) ≈ 13.7097`，Meeus 28.b 给出 13.7136，差 0.004 分。
- `1990-01-01 12:00 @118.18` → 真太阳时 11:49，经度时差 −7.28，均时差 −3.365。
- `2024-02-04 17:00 @120` → 均时差 −13.812；置 0 时时柱由 `庚申` 变为 `辛酉`。
- `2005-07-13 09:05 @120` → 辰时；置 0 → 巳时。
- 回归：`tests/true-solar-time-smoke.js`（8 组断言）。

## 后果

- 时辰交界附近的结果更接近天文事实；这与「真太阳时」这个名字的含义一致。
- 已发布的旧结果若在交界附近，可能与新版本不同——这类差异是**修正**而非漂移，
  变更记入 `CHANGELOG.md`。
- 均时差属于天文可验证量，与流派约定分开标注，不共用置信度口径。
